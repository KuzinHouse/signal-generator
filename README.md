# 🎛️ Signal Generator

Промышленный генератор сигналов с публикацией в MQTT и веб-интерфейсом.

## Возможности

- Генерация сигналов: Sine, Sawtooth, Square, Noise, Random, Constant + эффекты (дрейф, шум, выбросы, мёртвая зона, гистерезис, залипание, джиттер, тренд, потеря пакетов, деградация качества)
- Публикация в MQTT (rumqttc) с авто-реконнектом
- **Настраиваемый MQTT брокер**: хост, порт, пользователь/пароль, префикс топиков, топик диагностики — через UI (кнопка «⚙ НАСТРОЙКИ») или API
- **Персистентность настроек**: конфиг брокера и генераторов сохраняются в `config/` и переживают перезагрузку
- Формат: плоский JSON-LD (`@context`, `@id`, `generatedAt`, `value`, `unit`, `min`, `max`, `quality`)
- Топики: `{префикс}/{id}` (по умолчанию `USEPI/{id}`) + топик диагностики
- **Топик отображается на каждой панели генератора** — видно, куда публикуется сигнал
- REST API (actix-web): CRUD генераторов, toggle, текущее значение, **история сигналов**, настройки MQTT, тест подключения
- Веб-интерфейс без inline JS: SSR-панели, делегирование событий, canvas-графики (осциллограф на всю ширину + график нагрузки брокера)
- **Real-time через WebSocket**: дифф-снапшоты каждые 500 мс (только изменённые сигналы), полный раз в 5 с
- **Поиск/фильтр генераторов** по имени, id, топику + фильтр по типу волны
- **Счётчик тревог** (alarm/warning) в статус-баре — оператор сразу видит проблему
- **MQTT Last Will** — при падении процесса брокер публикует offline-статус в топик диагностики
- **Серверная история сигналов** — осциллограф сразу показывает прошлые данные при выборе канала
- **Favicon + версия приложения** в статус-баре
- **Опциональная авторизация API** (SIGNAL_API_TOKEN, Bearer для мутаций + защита WebSocket через ?token)
- **Экспорт/импорт конфигурации** — полный бэкап (генераторы + MQTT) одним JSON-файлом
- **TLS для MQTT** (use_tls в настройках брокера)
- Docker healthcheck
- Docker + docker-compose для деплоя

## Быстрый старт

```bash
cargo run --release
# Веб-интерфейс: http://localhost:8080
# API: http://localhost:8080/api/generators
```

## Настройка MQTT

В веб-интерфейсе: кнопка **«⚙ НАСТРОЙКИ»** в блоке статуса брокера. Поля:

| Поле | Описание |
|------|----------|
| Хост | Адрес брокера (IP или hostname) |
| Порт | Порт брокера (по умолчанию 1883) |
| Пользователь / Пароль | Опциональная авторизация |
| Префикс топиков | Шаблон `{префикс}/{id}` для сигналов генераторов |
| Топик диагностики | Куда публикуется диагностика каждые 10 сек + LWT offline |
| TLS | Шифрование соединения (порт 8883, системные корни) |

Настройки сохраняются в `config/mqtt.json` и применяются без рестарта (MQTT переподключается). При перезагрузке системы конфиг загружается автоматически.

### API

```bash
# История сигнала (для осциллографа)
curl 'http://localhost:8080/api/generators/temp-01/history?limit=120'

# Текущие настройки (пароль маскируется)
curl http://localhost:8080/api/mqtt/config

# Бэкап всей конфигурации (генераторы + MQTT)
curl http://localhost:8080/api/config/export > backup.json

# Восстановить из бэкапа
curl -X POST http://localhost:8080/api/config/import \
  -H "Content-Type: application/json" \
  -d @backup.json

# Обновить настройки
curl -X PUT http://localhost:8080/api/mqtt/config \
  -H "Content-Type: application/json" \
  -d '{"host":"192.168.1.10","port":1883,"username":"","password":"","topic_prefix":"USEPI","diagnostics_topic":"USEPI/diagnostics"}'
```

- `config/mqtt.json` — настройки брокера (persistence, не в git)
